OUR CHANGES (GPL version 2 section 2a)
--------------------------------------
Modified by davesgames.io, 2026-10-06. Each changed upstream file has a
notice of the change in its header.
  engine/patches/0001-web-update-tick.patch
      src-common/renderimpl.cpp: with CFDG_WEB, run() and drawShape() ask
      the shim for a time tick, in place of the GUI's timer thread.
  engine/patches/0002-antialias-switch.patch
      src-common/aggCanvas.{h,cpp}: aggCanvas::NoAntialias, a threshold
      gamma on the rasterizer.
  engine/patches/0003-std-views-reverse.patch
      src-common/builder.cpp: three reverse loops use std::views::reverse
      in place of backwards() from backwards.h.
  engine/shim/cfweb.cpp (new, ours): the C API of the web build. It
      takes the place of src-unix/main.cpp, posixSystem.cpp and
      pngCanvas.cpp. NFKC name normalization (ICU) is left out: names are
      compared as UTF-32.


CORRESPONDING SOURCE (GPL version 2 section 3)
----------------------------------------------
cf.js and cf.wasm are object code. Their complete corresponding source is
in this directory, at the same place as the binaries:
  engine/context-free-8cbef6e-src.tar.gz   upstream files used (git archive)
  engine/patches/                          our patches
  engine/shim/cfweb.cpp                    our C API
  engine/build.sh                          the build script
  engine/BUILD                             tool versions and output hashes
Build: EMSDK=<emsdk> BISON=<bison 3.x> FLEX=<GNU flex 2.6.4> engine/build.sh

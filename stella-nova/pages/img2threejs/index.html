Reconstruction by code

Image to Three.js

One drawing in, one procedural model out. Each object below was rebuilt from a single public-domain reference with the img2threejs skill: no mesh files, only primitives, swept curves and maps taken from the drawing.

    How it works

    The skill treats a picture as evidence, not as a mesh to trace. It reads the image in a fixed order: what the object is, its overall shape, the parts and how they join, then the materials. From that it writes a sculpt spec: a tree of parts, each with a primitive (a revolved profile, a swept curve, a box, a ring), a size and the way it attaches to its parent.

    A generator turns the spec into a Three.js factory, one pass at a time, and every pass is rendered and compared with the reference before the next one unlocks. Blockout checks the silhouette. The structural pass adds every part. Form refines curves and proportions. The material pass puts maps cut from the drawing on the parts. Surface, lighting, interaction and optimisation follow. A pass that does not match is sent back to the spec, and the review history records why.

    The scores on each pass are the reviewer's judgement of the render against the drawing, layer by layer. They are not a pixel metric. Where a later pass left the generated code unchanged, the card says so.

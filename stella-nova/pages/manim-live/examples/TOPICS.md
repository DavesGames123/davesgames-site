# Example topics

Each example file names ONE of these topics in its `# topic:` line. The
spelling must be exact; `node tools/build-catalog.mjs` stops on any other
value. The order here is the order of the topic list on the page.

- Animation
- Text & math
- Graphs & plots
- Calculus
- Linear algebra
- Geometry
- Probability & statistics
- Physics
- Algorithms
- Networks
- 3D
- Updaters & trackers
- Explainer patterns

Origami Simulator (web port) -- credits and licenses
=====================================================

This page is a web port of the origami desktop app (Rust, wgpu, winit). It
carries third-party work under the MIT license. The license text of each source
follows once at the end, as each repository requires. tools/build-library.mjs
writes this file from library.js and patterns.js.

1. Folding simulation
   Ported from Origami Simulator by Amanda Ghassaei.
   https://github.com/amandaghassaei/OrigamiSimulator
   Paper: A. Ghassaei, E. D. Demaine, N. Gershenfeld, "Fast, Interactive
   Origami Simulation using GPU Computation", Origami 7 (7OSME), 2018.
   Used in: sim.js, solver.js (the bar-and-hinge model, its constants, and the
   per-step passes, by way of the Rust port in src/sim/).

2. Pattern sources
   origamicp by Nihat Garibli, MIT. https://github.com/nihatgaribli/origamicp
     commit 58076815964d12b4df46a1c77a893ec51e308aa8
   flat-folder by Jason S. Ku, MIT. https://github.com/origamimagiro/flat-folder
     commit d50004815fb738d009e5b87b2307fbaefa717ef0
   Origami Simulator by Amanda Ghassaei, MIT. https://github.com/amandaghassaei/OrigamiSimulator
     commit 7855983a613c879c171b2b1557f8cd102d2640cf
   generated: original code in generators.js and patterns.js (this page).
   A .fold upstream file is an unchanged copy. An .svg or .opx upstream file
   was converted to a planar FOLD file by tools/svg2fold.mjs. On load, every
   pattern is fit into the centred unit square (patterns.js fromFoldText).

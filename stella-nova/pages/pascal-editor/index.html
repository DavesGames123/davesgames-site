Pascal Editor is a free, open-source, local-first 3D building editor (walls, rooms, levels, roofs, furniture) built with React Three Fiber and WebGPU. Copyright © 2026 Pascal Group Inc. It is licensed under the MIT License.

The frame below shows the official hosted editor at editor.pascal.app, which Pascal runs. davesgames.io did not write or change Pascal Editor, does not copy its files, and is not affiliated with or endorsed by Pascal Group Inc. Projects you make in the frame go to Pascal's service under its terms and privacy policy.

Why a frame: the open-source build is a Next.js server with a scenes API and a SQLite store. This site is static files only, so it cannot run that build unchanged. To run the pinned open-source release on your own computer (Node.js 22.13 or newer), use npx @pascal-app/cli editor. It keeps your projects on your disk.

About

Each pattern is a small program: the sliders and the seed go in, and a list of vector shapes comes out. The same seed always gives the same shapes, so a design can be made again from its numbers. The SVG file keeps these numbers in its description.

Modifiers act on the shapes after the pattern makes them, from the top of the list to the bottom. A warp bends every line, a mask cuts lines at the edge of a shape, and a clip sets a hard edge in the file.

The SVG has a viewBox and, for A sizes, a width and height in millimetres, so it opens at print size. The PNG export writes its DPI into the file.

All patterns, modifiers and code here are original work for davesgames.io. See also bookofshapes.com by Nikolaj Sokolowski, a pattern site in the same genre. Nothing on this page is taken from it.

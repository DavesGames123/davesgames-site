# Periodic Table — credits and licences

## Element data

`data/elements.js` is generated by `build/build-data.py` from two open data sets.
The script and its corrections (`FIX_CFG`, `FIX_DISC`, `FIX_TEXT`) are ours.

- **komed3/periodic-table** by Paul Köhler — <https://github.com/komed3/periodic-table>,
  commit `aa8502320726c7210c7069a3fc1673c61e6988ad`, MIT licence (text below).
  Used: `_db/elements.json` (numbers) and `_db/nuclides.json` (isotopes).
  Not used: its prose, its pages and its images.
- **PubChem periodic table** (NCBI, US National Library of Medicine) —
  <https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON>, a US government
  work in the public domain. Used: CPK colours, electron affinities and
  fall-back values.

The prose in `data/text.js` (name origin, uses, description) is written for
this page. It is not copied from either data set.

The pseinfo project (<https://github.com/pseinfo>, MIT) was read as a
reference for the data layout. No pseinfo file or text is used.

## Atomic structure

`atom.js` imports the hydrogen radial functions and spherical harmonics from
`../hydrogen-table/physics.js` (this site). Effective nuclear charges use
Slater's rules (J. C. Slater, *Phys. Rev.* 36, 57 (1930),
doi:10.1103/PhysRev.36.57).

## Colour maps

Heat maps use `../ct-lab/colormaps/` (this site); the sources of each map are
in `../ct-lab/colormaps/CREDITS.md`.

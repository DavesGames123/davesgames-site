How it grows

attractor influence radius di mean direction kill distance dk

Space colonisation

The plant competes for space. First, attractor points fill the shape of the crown: an ellipsoid for the oak, a cone for the conifer, a hollow dome for the willow, a vase for the fern.

In each step, each attractor finds the nearest node of the plant. It pulls that node only when the node is nearer than the influence radius di. Each pulled node adds one segment of length D. The direction is the mean of the unit vectors to its attractors, plus small tropism terms: up to the light, level for the whorls of a conifer, down for the shoots of a willow.

When a node comes nearer than the kill distance dk, the attractor dies. The crown fills, the attractors run out, and the growth stops. Branches never cross, because two branches cannot take the same space.

Thickness: the pipe model

Each tip is a thin pipe that runs down to the root. A branch carries all the pipes of the branches above it, so rparentp = Σ rchildp, with p near 2.5. The trunk gets thicker each time a new tip grows. The "Flow" colour shows how many tips each branch carries.

Roots: diffusion-limited aggregation

Roots and dendrites look like DLA. The roots grow with the engine of the Diffusion-Limited Aggregation page, a port of fogleman/dlaf. Particles start on a sphere in the soil below the plant and walk at random. They join the roots where they first touch them. dlaf lets a program change the walk with hooks. This page sets three: randomStartingPosition starts each walker deep in the soil, motionVector adds a small drift toward the root crown, and shouldReset sends back a walker that leaves the soil. The walkers come from below, so the deep tips catch them first and the roots grow down.

Colours

Natural shows bark and leaves. The heatmaps colour each node by age (the growing tips glow), branch order, flow, height or a light estimate (the nodes above a node shade it). A gradient change recolours the plant at once.

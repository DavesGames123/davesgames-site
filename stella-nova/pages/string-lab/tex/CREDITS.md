# String Lab wood textures

All files in this folder are CC0 (public domain) photo scans. We resized
them to 1024 px, recompressed them and changed some colours. No
attribution is required. We credit the sources anyway.

| Files | Source | Author | Changes |
|---|---|---|---|
| spruce-color/normal/rough.jpg | ambientCG, Wood 022 (ambientcg.com/a/Wood022) | ambientCG (Lennart Demes) | colour: brightness 106 %, saturation 85 % |
| rosewood-*.jpg | Poly Haven, Rosewood Veneer 1 (polyhaven.com/a/rosewood_veneer1) | Jenelle van Heerden | none |
| mahogany-*.jpg | Poly Haven, Sapele Veneer (polyhaven.com/a/sapele_veneer) | Jenelle van Heerden | none |
| ebony-*.jpg | Poly Haven, Fine Grained Wood (polyhaven.com/a/fine_grained_wood) | Rob Tuytel | colour: brightness 42 %, saturation 55 % |
| maple-*.jpg | Poly Haven, White Maple Veneer (polyhaven.com/a/white_maple_veneer) | Jenelle van Heerden | none |
| flame-color.jpg | the maple colour map above | — | flame bands added in code (22 per tile, about ±30 % brightness) |

Each set has a colour map (sRGB), an OpenGL normal map and a roughness map.
flame uses the maple normal and roughness maps.

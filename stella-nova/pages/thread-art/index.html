Thread Art

One thread, wound peg to peg around a frame, draws the image. At each peg the GPU scores every line to every other peg and lays the one that lowers the error most.

Board

Opacity sets how much one line darkens (or, on a black board, lights) the pixels under it. Width changes the drawing only: 1 is one model pixel. The seed picks the start peg of each thread.

Lay the thread

The error image shows what each pixel still lacks: the part of the image no thread has drawn yet. Red marks pixels with more thread than the image has. Wheel or pinch to zoom, drag to move.

Export

PNG: 2048 px. SVG: one line element per thread line. JSON and text: the peg sequence of each thread, to wind a real piece. Peg 0 is at the top; numbers go clockwise.

About

After the idea of image-stylization-threading by Jérémie Piellard (live demo), a string-art method that Petros Vrellis made known. This page is our own code: an optical-density model, an exact squared-error greedy step and WGSL compute kernels. Images: public-domain paintings, a NASA photo and shapes of this page.

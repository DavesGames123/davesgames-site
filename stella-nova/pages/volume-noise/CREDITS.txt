What is this page's own
  - The views (slice, tiles, volume cube) in shaders/views.wgsl.
  - The cloud layer renderer in shaders/clouds.wgsl. It follows the
    published model (coverage remap, erosion, Beer's law, powder, Henyey-
    Greenstein phase, multiple-scattering octaves) but it is not a port of
    any published shader.
  - The 2D weather (coverage) texture: main.cpp makes no such texture.
  - The seed: the original has none. Seed 0 gives the original values.
  - Every image the page shows is computed in the browser. No sample image
    of the original repository is included.

Changes from the original, and why
  - The hash fract(sin(n + 1.951) * 43758.5453) is computed on the CPU in
    float steps and uploaded as a table, because a GPU sin() is not exact
    enough near n = 20000 for that product. The values are the same.
  - floor(x / 289), floor(x / 7) and the integer mod add 0.5 before the
    division, so that a fast GPU reciprocal cannot change the integer.
  - The detail texture keeps the packed value in A (main.cpp writes 255 to
    A and the packed value to a second file). The page also keeps a "parts"
    texture with the Perlin FBM, the Perlin-Worley Worley FBM, one Worley
    octave and the packed shape, so each part can be shown.

What is WASM-4?

WASM-4 is a fantasy console by Bruno Garcia and contributors: a games machine that exists only as a specification and a runtime. A game is a WebAssembly module of 64 KB or less. The screen is 160 × 160 pixels with four colours from a palette that the cart can change. Input is up to four gamepads with a d-pad and two buttons, X and Z, and a mouse. Sound comes from four channels: two pulse waves, a triangle and noise. A cart can save 1024 bytes.

Because the cart is plain WebAssembly, it can be written in any language that compiles to it: C, Rust, Zig, Go, AssemblyScript, Nim, Odin and more. The console gives each cart one 64 KB page of memory. The framebuffer, palette, gamepads and mouse are at fixed addresses in that memory, and the cart calls a small set of functions: blit, rect, line, oval, text, tone, diskr and diskw. The console calls the cart's update 60 times a second.

This cabinet runs a JavaScript port of the official WASM-4 web runtime (ISC licence). The CRT is our own: a WGSL shader with barrel glass, a beam for each of the 160 lines, an aperture grille, bloom, flicker and the static of a channel change. With no WebGPU, the page uses the 2D tube of our slow-scan television page. Turn the CRT off to see the plain pixels.

ABOUT

A standing wave is two equal waves that travel in opposite directions. Their sum does not travel. Each point only moves up and down.

The edge is fixed, so u = 0 there. Only waves that fit a whole number of half wavelengths survive. These are the modes (m, n). A square gives sine modes. A drum gives Bessel modes Jm(kr)·cos mθ.

In one mode, ∂²u/∂t² = −ω²u. The acceleration map is then the height map times −ω². It is brightest at the antinodes and zero on the nodal lines.

Add a second mode with a different ω, and that proportion breaks. Each mode has its own ω², so the acceleration is a different mix of the two shapes.

## Candidates (split later, each needs a browser check)

These files mix concerns, but each one has a SECTION MAP header and
shares mutable module state across its sections, or is one large
closure. A split must move `let` state into a shared state object or
pass it in, and that is a logic change. The rule since 2026-10-07 is
no headless browser, and most of these pages have no node tests.
Split each one only with its owner and a manual browser check.
